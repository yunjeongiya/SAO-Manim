# /blog - 블로그 글 초안 생성

최근 완료한 Feature를 바탕으로 블로그 글 초안을 자동 생성합니다.

## 실행 순서

### 1. 최근 완료 작업 확인
- `docs/features/INDEX.md`에서 가장 최근 COMPLETED Feature 찾기
- 해당 Feature의 README.md 읽기
- Git log 확인하여 실제 변경사항 파악

### 2. 블로그 초안 작성
다음 구조로 `{Feature폴더}/blog.md` 생성:

```markdown
# [블로그 제목]

> 작성일: YYYY-MM-DD
> Feature: FXXX - [Feature Name]

## 🎯 배경 및 동기

[왜 이 작업을 했는가?]

## 💡 주요 내용

[무엇을 만들었는가?]

### 기술적 구현
- 사용 기술/라이브러리
- 핵심 알고리즘/접근법

### 코드 예시
```언어
[핵심 코드 스니펫]
```

## 🔧 구현 과정에서의 고민

[어떤 어려움이 있었고 어떻게 해결했는가?]

## 📊 결과

[스크린샷, 성능 개선 등]

## 🎓 배운 점

[이 작업을 통해 얻은 인사이트]

## 🔗 참고 자료

- [관련 링크들]
```

### 3. 사용자 리뷰 요청
- 초안을 보여주고 수정 사항 확인
- 추가할 내용이나 빠진 부분 확인

## 사용 예시
```
사용자: /blog
Claude: 최근 완료한 F001 작업을 바탕으로 블로그 초안을 작성했습니다.
        [초안 경로 제공]
```

## 참고
- 이 명령어는 작업 완료 후 선택적으로 사용
- `/finish` 명령어와는 별개로 실행 가능
